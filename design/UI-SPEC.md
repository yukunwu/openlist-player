# 静映 / Quiet Cinema

## 0.1.3 配色修订（优先于下方初版配色）

用户认可播放器布局，但拒绝深绿色。当前实现保留布局、菜单位置和交互，仅转为参考 Netflix
黑白红层次的中性影院风格，不使用其品牌图形。原始生图保留为历史参考，不代表当前配色。

- 背景：`#232323 → #141414 → #090909`，窄导航使用44%黑色。
- 正文 `#F5F5F5`、次文 `#B3B3B3`；图标统一白灰，取消暖金与薄荷。
- 列表默认5%白色填充，选中14%白色；遥控焦点使用浅白细框，不能只靠红色区分焦点。
- 菜单90%中性黑灰 `#E61A1A1A`、25%白色细边；保持足够遮盖避免亮画面损害文字可读性。
- 播放器顶部70%黑渐隐，底部65%黑渐隐，移除整幅视频的均匀深色遮罩；不加入实时模糊。
- 红色 `#E50914` 仅用于品牌小标、播放进度及系统强调；HUD填充保持白色。
- App窗口本身保持不透明：半透明指内容上的叠层，不透出手机桌面或其他应用。

`preview.html` 已同步中性UI配色；原始海岸示意不是新增播放背景。

这是可实现的视觉与交互规格，不是已发布功能或真机验收结论。设计只使用合成目录、文件名和本地矢量，不读取账号、媒体 URL 或设备数据。

## 方向

让文件和画面成为主体，而不是按钮。沿用现有深青灰、薄荷和暖金语汇，取消厚重的满底圆角按钮、橙色粗框和大标题。列表像精心排版的目录，播放器像画面上的轻薄字幕。

- 保留 84dp 导航轨；不改成宽侧栏，不加首页海报、推荐流或虚构缩略图。
- 保留同一横屏布局供 TV 遥控器和手机触摸使用，不新增独立手机布局。浏览器预览等比缩放用于展示，不代表 Android 必须把整个 View 树缩小。
- 顶部只占 64dp；20sp 目录标题和品牌同一行，路径与统计下一行。所有额外说明放底部或首次使用提示，不侵占常驻列表区。
- 播放器上方只有视频信息，没有返回、比例、亮度或速度按钮。

## Token

尺寸以 dp、文字以 sp 为准；预览的 960 × 540 逻辑画布按 1 CSS px = 1dp 示意。

| Token | 数值 | 用途 |
| --- | --- | --- |
| canvas | `#10191D` | 主底色；仅一层极淡径向渐变 |
| rail | `#0C1418` | 左轨，与主区以 1dp 细线分隔 |
| surface | `#172429` | 菜单与轻微行底色，不做模糊 |
| text | `#EDF3EF` | 主文字 |
| secondary | `#A3B5B3` | 元信息 |
| quiet | `#78918F` | 非关键装饰；不可用于必须读懂的操作 |
| mint | `#A4DFC6` | 焦点与进度 |
| amber | `#D8BA7B` | 文件夹图标，不用于焦点 |
| focus-fill | `#243C35` | 聚焦行/菜单项 |
| divider | 白色 7% | 行间或栏线 |
| spacing | 4 / 8 / 12 / 16 / 24 / 32 | 不任意增加留白 |
| radius | 行 8 / 菜单 10 / 动作 6 | 避免满屏胶囊 |
| stroke | 普通 1 / 聚焦 2 / 图标 1.5 | Android 使用 dp 转 px，不直接传裸 px |

字体：品牌可用系统 `serif` 字族做小号 editorial 对比；正文中文使用设备 sans-serif，数字使用 sans-serif 的 tabular 或 monospace 字族。无需下载字体，不引入新的字体依赖。目录标题 20/28 medium；文件名 16/22 medium；路径/元信息 12/18；动作 14/20 medium；导航文字 11/16；媒体名 16/22；媒体规格 12/18。Android fontScale 变化时保留可读性、允许次要信息省略，不能裁切主操作。

## 文件库

960 × 540 下：导航 `x=0,w=84`；主内容 `x=108,right=24`。内容顶部 12dp。标题行高 32，路径行高 26，尾距 6，共 64。列名行高 20。列表占剩余空间，底部提示高 22。1080p 电视由设备 density 映射，不直接按物理像素硬编码。

- 导航：图标 22dp、文字距图标 5dp；触点 60×58，项间 7。品牌标记 32dp。服务器入口底部对齐。当前页使用薄荷图标/左侧 2×18 短线；键盘焦点再加 2dp 外框，区分“当前页”和“聚焦”。
- 文件行高 72dp，左右内距 16，行间 4。图标 24，图标到标题 16。标题与次行间距 3。右侧为大小 + 箭头；不要为每个文件放一个“播放”按钮。
- 文件夹用暖金线框，视频用灰绿线框；不根据扩展名猜测分辨率、编码或观看进度。文件页示例只显示已知扩展名和大小。
- 聚焦：2dp 薄荷框、轻薄底色、左侧短刻度；不放大行高、不跳动布局。按下颜色加深，120ms；焦点变化 140ms；页面入场仅 220ms 渐显，避免逐行长动画阻挡操作。
- 文件名单行省略，聚焦停留 700ms 后按现有 marquee 滚动；移出立即停止。目录路径首部省略，保留当前位置。
- 单击/短按 OK：文件夹进入，视频直接内部播放。长按视频 500ms：行内锚定菜单，只有“内置播放”“外部播放器”。长按触发后必须吞掉同一轮短按，避免菜单出现又开始播放。
- 菜单宽 208dp、边距 6、项高 48、文字 14；对齐目标行右端，默认向下，空间不足翻到行上方；边缘安全距离 16dp。文件行仍可辨识，无居中遮罩对话框。
- 菜单打开先聚焦第一项；上下只在菜单内循环，左右不得快进/切目录；OK 只执行选项；Back/点击外部关闭并把焦点还给原行。选择外部播放器后系统应用选择器仍由系统提供，不模拟已启动。
- 加载态保留原列表位置，底部显示加载状态、避免焦点重置；空目录显示简短标题与返回动作；错误保留路径并提供重试，不用虚构条目填满。

## 播放器

顶层视频全屏；演示 HTML 中的抽象海岸由 CSS/SVG 构成，仅代表合成样片，不是应用应联网加载的背景。

- 顶部信息左上 `(24,18)`，右边留 24。视频名一行 16sp，规格次行 12sp；过长省略。规格仅展示已从播放轨道确认的字段；未拿到数据不显示假 `4K/HDR`。
- 顶部渐隐遮罩高 96dp，底部高 148dp，无模糊和实体工具栏。标题随控制层隐藏，不常驻覆盖视频。
- 进度横向距边 24，底部 78；可视轨 3dp、焦点轨 4dp，触摸目标至少 48dp 高；当前进度薄荷，缓冲白 28%，未播放白 17%。时间 12sp，固定数字宽度，避免跳动。
- 底行距底 16，触点高 48；播放/暂停左侧 48×48，比例与速度最右侧，分别最小 72×48 与 64×48，间隔 8。默认无实底，聚焦用薄荷细框与 10% 薄荷底。
- 比例文案严格为“原始 / 4:3 / 16:9 / 拉伸”；“原始”为保持源比例的 FIT，不是画面裁切。比例与速度都只点开锚定菜单，不能点击直接轮换。
- 菜单宽 180dp，位于对应按钮上方 8dp、右边对齐；每项 48dp。当前值有小勾，键盘焦点另有背景；当前值和焦点不要混成同一状态。
- 本预览速度集合 `0.5× / 0.75× / 1.0× / 1.25× / 1.5× / 2.0×`；实现以既有 PlaybackPolicy 为准。关闭后焦点回原按钮，菜单存在期间不自动隐藏控制层。
- 普通播放时控制层 4 秒无操作后消失；暂停、菜单或正在拖进度时不消失。点击空白只唤出/收起控制层，不另加双击语义。

## 手势与锁定

只对触摸设备启用锁定入口及左右边缘手势。TV 不新增触摸指引。锁定的是应用内触摸，不声称阻止 Android 系统导航/通知或物理电源键。

- 锁定入口在左侧中线，48×48dp，细线锁图标，无厚底；显示控制层时出现。锁定后隐藏顶部、底部、菜单和所有 HUD，只留下同位置“解锁”触点（锁开图标、可访问名称“解锁画面”）。
- 锁定后全屏点击、拖动、长按、快进、暂停、比例、速度及应用返回都不能操作；唯有明确点击解锁控件恢复。避免一次触摸同时解锁又触发底层视频。菜单打开时先关闭菜单再锁定。
- 左侧 35% 区域：先静止长按 500ms，反馈小太阳图标后再上下滑调当前窗口亮度。长按前移动超过 12dp 取消候选，不把普通滑动误识别为亮度。上滑增加，下滑降低。
- 右侧 35%：超过 12dp 垂直阈值即调媒体音量。中央 30%、顶部 64dp、底部 96dp 及所有按钮/菜单/进度条区域不触发手势。横向位移主导则放弃，不和导航冲突。
- HUD 距左右边 26dp，轨宽 3dp、高 120dp，图标 16，数字 11sp；透明底、白色 22% 轨、薄荷填充。不显示实心大卡片，也不常驻亮度按钮。
- 放手后 800ms 延迟，再 180ms 淡出；再次操作复用同一个 HUD，亮度和音量不会堆叠。亮度仅 `Window.screenBrightness`，不写系统亮度；音量只用媒体流，遵从系统可用上下限。

## 遥控器状态机

| 状态 | OK | 左 / 右 | 上 / 下 | Back |
| --- | --- | --- | --- | --- |
| 沉浸播放 | 播放 / 暂停 | -10 / +10 秒，边界夹取 | 显示并进入控制栏 | 返回文件库 |
| 控制栏导航 | 执行聚焦动作 | 控件间移动；焦点在进度条则 seek | 按既定焦点图移动 | 先隐藏控制栏 |
| 锚定菜单 | 选择当前项 | 不透传给播放器 | 菜单内移动 | 关闭并归还焦点 |
| 触摸锁定 | 不操作 | 不操作 | 不操作 | 不退出应用内播放 |

优先级：锁定 > 菜单 > 控件焦点 > 播放快捷键。不要在 Activity 顶部无条件把所有方向键发给 PlayerView；消费 DOWN 后对应 UP 也必须消费。OK 长按开文件菜单不能顺便触发短按；播放快捷键按一次完成一次，不为一次按键显示多个反馈。seek 提示居中只留 `+10 秒` / `−10 秒`，短暂显示 600ms。

## 实现映射与边界

- `TvStyle`：已有 browserFocus 与通用 focus 不一致，建议只对文件浏览/播放器的轻量 action 使用新 token，不必重做账号表单；圆角/描边统一经 dp 转换。
- `MainActivity`：保留现有 84dp rail、20sp masthead、ScrollView/原列表逻辑。只替换 row 状态、动作样式与长按锚定菜单，不引入新图片、网络请求、数据库或推荐信息。
- `PlayerActivity`：复用 Media3 controller/现有 action，按状态管理 info、锁定、HUD、菜单；Android `PopupWindow` 负责锚定与焦点归还，绘制式 HUD 减少层级。
- 不通过视觉稿决定网络认证、签名、升级、设备安装或播放协议。设计文件不修改这些代码，不触碰真实设备。
- `preview.html` 可离线打开；支持触摸长按文件、菜单、播放暂停、方向键、比例/速度、应用锁定及手势演示。预览工具栏属于设计验证工具，不是 App UI。
- 浏览器验证不代表真机 TV 可用；需独立验 720p/1080p、字体缩放、真实遥控器长按、系统返回、Media3 焦点、手机多点触摸/取消事件、手势阈值和系统音量。

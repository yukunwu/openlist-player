# Android 与播放兼容性

截至 2026-10-23。安装门槛、代码具备的能力、实际验证是三个不同层级。

## Android

| 系统 | 安装与支持边界 | 验证状态 |
| --- | --- | --- |
| Android 5.1 及以下 / API 22 及以下 | 不支持安装 | minSdk 为 23，不提供降级包 |
| Android 6.0–7.1 / API 23–25 | 满足最低安装要求；旧 TLS、系统解码器和固件差异可能限制播放 | 尚无本应用的真机完整回归；其他项目旧电视的测试不算本应用验证 |
| Android 8–14 / API 26–34 | 代码目标兼容；TV 遥控器与手机触摸分别处理 | 尚未逐版本、逐电视验证 |
| Android 15 / API 35 | 当前 targetSdk/compileSdk 为 35 | 构建和 Lint 通过，不等于 Android 15 真机验收 |
| Android 16 / API 36 | 已在一台小米手机安装、启动、读取目录并观察到 H.264/AAC 播放 | 部分手机交互仍待回归；不能代表所有 Android 16 设备或 Android TV |
| 更高版本 | 没有设置 maxSdk，但不承诺未来版本兼容 | 未验证 |

- TV 与手机使用同一个横屏界面，具有 Leanback 和普通桌面入口；手机额外提供亮度、音量和画面锁定手势。
- 无 Google Play Services 依赖，不要求 root；需要网络、网络状态与媒体音量权限。
- 4K、HEVC、HDR、杜比、AV1、音频直通取决于系统解码器、具体片源与带宽；Android 版本足够不代表这些能力一定可用。
- 未提供内置软件转码、NAS 转码控制、DRM 许可证配置、云盘会员加速或浏览器登录挑战处理。
- 目前正式签名 APK 已构建/验签，但真机安装记录为 debug 同签名覆盖升级；不能把两者混为一谈。

## OpenList 接入方式

本应用是 **OpenList HTTP API 客户端，不是 WebDAV 客户端或网页壳**。主要使用：

- `/api/auth/login`：用户名、密码和可选 OTP 登录。
- `/api/fs/list`：分页目录列表。
- `/api/fs/get`：获取文件 `raw_url`，交给内部 Media3 或用户选择的外部播放器。

没有硬编码默认服务器或账号。登录表单默认留空；扫码仅在用户明确确认后填入。
已有已认证会话仍可自动恢复。未配置服务器时不发起目录请求。

尚未建立 OpenList 服务端版本测试矩阵，不能写成“所有 OpenList/AList 版本通用”。
需要上述 API 及兼容的响应格式；目录密码、SSO、WebAuthn 等登录流程尚未接入。

## 播放策略

| 策略 | 当前行为与边界 |
| --- | --- |
| HTTP(S) 云盘/CDN 直链 | `raw_url` 可直接访问时，由手机/电视请求媒体，不经过本应用自建中转；签名、有效期、IP/UA 约束仍由云盘决定 |
| HTTP 301/302/303/307/308 跳转 | 内部播放器最多处理 8 次请求；跨源不附带原源额外头，拒绝 HTTPS 降级 HTTP。外部播放器有自己的跳转策略 |
| OpenList 服务端代理 / Web Proxy / 必须代理的存储 | 若 API 返回可访问的代理 URL，则直接播放该 URL；媒体流量经过该代理。客户端不强制直链，也不自动切换服务器策略 |
| 需要 Cookie、Referer、特定 UA 等额外请求头 | `/api/fs/get.header` 是页面元数据，客户端不再把它当作媒体头。需要额外头的存储请在 OpenList 配置 Web Proxy，由服务器处理；客户端不调用需要管理员权限的 `/api/fs/link`，不自动修改服务器设置 |
| HLS `.m3u8` / DASH `.mpd` | 已集成对应 Media3 模块；清单、分片、密钥须能通过 HTTP(S) 访问。跨源分片不自动继承原源凭据，DRM 未配置；尚无完整实流矩阵 |
| 普通视频文件 | MP4/MKV 等扩展名会进入播放流程，但是否可解复用/解码取决于 Media3 与设备，不把扩展名识别当作编码支持证明 |
| 快进/拖动 | 使用 HTTP Range。源忽略 Range 时当前会下载并丢弃前面的字节，长视频可能慢且耗流量；已校验 206 起点/长度，416 仅在恰好文件末尾时作为 EOF 处理 |
| 链接过期 | 不自动重新向 OpenList 获取 URL；需要返回目录重新打开。播放器“重试”仅重试当前 URL |
| 外部播放器 | 仅传递播放 URL 和标题；本应用不传递 OpenList 会话令牌。接收应用会获得临时签名链接，需选择可信应用 |

上游源码核对基于 OpenList `fbbded2f904e99e2cd642776269d5e297a3c2779` 的
`server/handles/fsread.go`：`MustProxy` / `WebProxy` 会影响 `raw_url`，`header` 是页面元数据字符串。
这证明当前上游的 API 语义，不代表用户服务器恰好运行这一版本。

## 云盘验证记录

| 存储 | 播放结果 | 路径证据 |
| --- | --- | --- |
| 移动云盘 | 用户确认当前使用直链播放；此前已有网页/WebDAV 跳转与 Range 206 验证 | 当时返回云盘 CDN；未逐次抓取本应用当前会话的完整网络链，不能保证所有文件/设置永远直连 |
| 天翼云盘 | **用户于 2026-10-23 确认可播放** | 尚未验证此播放实例是直链、跳转还是 OpenList 代理；不推断分辨率或所有编码均可用 |
| 阿里云盘、百度网盘、夸克、115、OneDrive、Google Drive 等 | 尚未逐一验证 | 满足 API、可访问媒体 URL、鉴权与解码条件时可能可播；不列为已认证支持 |

云盘挂载成功、浏览器能播放、App 能播放、媒体不经 NAS 是四件不同的事。是否转发取决于
最终请求地址、重定向链与服务器策略，不只取决于云盘名称；使用私人链接验证时不得公开签名、令牌或账号。
